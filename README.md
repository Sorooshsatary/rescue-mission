# Rescue Mission — مأموریت نجات

بازی آموزشی فارسی و راست‌چین که دانش‌آموزها با یک Strategy Builder بصری، رفتار ربات نجات را با قانون‌های IF-THEN طراحی می‌کنند — بدون کدنویسی و بدون درگیری مستقیم با Q-Learning.

## چی توش هست

- **Strategy Builder بصری:** ۱۴ شرط و ۸ اقدام، آستانه باتری ۲۰ / ۳۰ / ۵۰ / ۷۰٪، افزودن، حذف و جابه‌جایی اولویت قانون‌ها، اعتبارسنجی قوانین ناسازگار، ۶ استراتژی آماده (نجات‌محور، ایمنی‌محور، امتیاز و سرعت، محافظه‌کار باتری، متعادل هوشمند، مسیر امن) و ذخیره چند استراتژی نام‌دار
- **اجرای زنده:** قدم‌به‌قدم و خودکار، با مسیریابی واقعی روی شبکه ۱۲×۱۲
- **Decision Inspector:** در هر قدم نشان می‌دهد کدام قانون برقرار شد و چرا
- **Replay:** بازپخش کامل مأموریت
- **آزمایشگاه Q-Learning:** آموزش روی ۴۰۰ مأموریت و مقایسه استراتژی دانش‌آموز با عامل RL روی ۳۰ نقشه یکسان، شامل آزمایش تغییر محیط (ظرفیت حمل ۲ به ۱)

استراتژی‌های ذخیره‌شده در `localStorage` مرورگر می‌مانند (کلید `rescueMission.savedStrategies.v1`) و با رفرش یا بستن صفحه از بین نمی‌روند. `localStorage` مخصوص همان مرورگر و دستگاه است.

## اجرا

### روی GitHub Pages

بعد از فعال‌کردن Pages روی شاخه `main`، بازی از این آدرس باز می‌شود:

https://sorooshsatary.github.io/rescue-mission/

### لوکال

فایل `index.html` را مستقیم در مرورگر باز کنید، یا در همین پوشه:

```bash
python3 -m http.server
```

بعد `http://localhost:8000/` را باز کنید.
